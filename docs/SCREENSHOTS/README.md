# Screenshots

This folder contains screenshots of ClawChat features.

## Multi-Agent Monitoring

Screenshots will be added here as the feature is used and tested.

### Agent Control Center

Expected screenshots:
- `agent-control-center-dark.png` - Dark mode agent overview
- `agent-control-center-light.png` - Light mode agent overview
- `agent-detail-sheet.png` - Bottom sheet with agent details
- `grid-list-toggle.png` - Grid vs List view comparison

### How to Add Screenshots

1. Capture screenshots from iOS Simulator or device
2. Name them descriptively (e.g., `agent-card-dark.png`)
3. Add them to this folder
4. Update this README with descriptions

### Guidelines

- Use iPhone 15 Pro or similar modern device for captures
- Capture both dark and light mode variants
- Include device frame if possible
- Keep file sizes reasonable (< 1MB each)
