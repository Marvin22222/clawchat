# ClawChat

## Description
A native iOS app for OpenClaw - your personal AI assistant.

## Features
- Secure Gateway Token Login
- Real-time Chat
- Agent Management
- Task Monitoring
- Dark/Light Mode
- Voice Input
- Image Upload

## Getting Started

```bash
# Install dependencies
flutter pub get

# Run on iOS Simulator
flutter run -d "iPhone 15 Pro"

# Build for iOS
flutter build ios --release
```

## Requirements
- Flutter 3.x
- Xcode 15+
- iOS 14.0+
